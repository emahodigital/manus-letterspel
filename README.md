# Manú's Letterspel

Een leesspel voor één jongen van 7: letters vangen, woorden bouwen en lezen, en een eigen wereld laten groeien.

Het spel is van één gezin. Het start alleen met de gezinscode; het spel zelf en de stemmen van het gezin staan versleuteld in `geheim.bin`.

Adres: https://emahodigital.github.io/manus-letterspel/

Op de iPhone: open het adres in Safari, tik op het deel-icoon en kies "Zet op beginscherm". Voer daar één keer de gezinscode in. Daarna werkt het spel ook zonder internet.

Plaatjes: Fluent Emoji (MIT, Microsoft). Lettertypen: Andika en Baloo 2 (SIL Open Font License). Stem: Kitten TTS (Apache-2.0). Effecten en muziek: eigen noten op GeneralUser GS. Zie LICENTIES.md.
